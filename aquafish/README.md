# Aquafish (Fabric 1.21.1)

Сборка (нужны JDK 21 и Gradle):
    gradle wrapper --gradle-version 8.10
    ./gradlew build
Готовый мод: build/libs/aquafish-1.0.0.jar (нужен Fabric API)

Крафт:
- Аквариум: стекло x3 (верх), стекло + ведро воды + стекло (середина), песок x3 (низ)
- Корм (x4): сушёная ламинария + семена пшеницы + костная мука (бесформенный)

Игра:
- ПКМ ведром с рыбой (лосось / треска / тропическая «Немо» / иглобрюх) - посадить (до 6 шт.)
- ПКМ пустым ведром - достать последнюю рыбку
- ПКМ кормом - анимация высыпания, сытые рыбки радуются 3 минуты
- ПКМ пустой рукой - сколько рыбок внутри
